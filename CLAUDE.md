# Project instructions

## Task tracking
- Keep a checklist in `TASKS.md` at the repository root. Tick each item when it is done, and add anything new you find.
- To see where a run stands, read `TASKS.md`, not the conversation scrollback.

## Answers
- Once a question has been answered, treat that answer as done. Focus on the current request, and don't go back over an earlier answer unless the user asks about it or points out a problem with it.
